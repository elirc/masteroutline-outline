# Domain Glossary

Product nouns, their code homes, and the confusables that trip up newcomers. In interviews, using a codebase's domain language precisely ("membership", "revision", "share") is a strong signal that you actually worked in it.

## Confusables and near-synonyms

- **`data` vs `text` vs `content` vs `state` (document body).** The API accepts/returns ProseMirror JSON as `data` (newer, `x-api-version ≥ 3`) or Markdown `text` (legacy) — see [presenters/document.ts L38–68](../../server/presenters/document.ts#L38-L68). The DB column `content` holds ProseMirror JSON; `state` holds the binary Yjs CRDT. Mixing these up is the #1 newcomer confusion.
- **Processor vs Task.** Both run on Bull queues in the worker. A *processor* reacts to bus events and declares `applicableEvents` ([BaseProcessor](../../server/queues/processors/BaseProcessor.ts)); a *task* is scheduled explicitly with props ([BaseTask](../../server/queues/tasks/base/BaseTask.ts)). Processors often just schedule tasks.
- **`Event.create` vs `Event.schedule`.** `create` persists an audit row *and* enqueues; `schedule` enqueues without persisting ([Event.ts L136–148](../../server/models/Event.ts#L136-L148)). Choosing wrong either pollutes the audit log or silently drops audit history.
- **Share vs Shared-with.** A `Share` is a public link. "Sharing with a user" is a `UserMembership` on the document. Different models, different policies.
- **Archive vs Trash (delete).** Archived docs keep their place but are hidden (`archivedAt`); deleted docs go to trash (`deletedAt`, paranoid delete) and are purged later by [CleanupDeletedDocumentsTask](../../server/queues/tasks/CleanupDeletedDocumentsTask.ts). Different policies (`archive` vs `delete` in [document policy](../../server/policies/document.ts#L179-L245)), different lifecycle.
- **Viewer (role) vs View (model).** A viewer is a read-only user role; a [View](../../server/models/View.ts) row records "this user viewed this document" and powers insights/popularity.
- **`documents.update` (API) vs `documents.update` (websocket event) vs `documents.update.debounced` (bus event).** Same string, three planes: RPC endpoint name, socket.io message, and a debounced bus event consumed by processors like [RevisionsProcessor](../../server/queues/processors/RevisionsProcessor.ts#L10-L14). Context tells you which plane you're on.
