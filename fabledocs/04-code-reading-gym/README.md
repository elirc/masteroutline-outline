# 04 — Code Reading Gym

Reading code precisely is the most undertrained engineering skill and the most tested one (every debugging round, every review round, every "walk me through this" starts with reading). This module is pure reps.

| Page | Rep type |
| --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | 10 real excerpts → annotate inputs/outputs/invariants/side effects/failure modes |
| [02-trace-tables.md](02-trace-tables.md) | 5 step-by-step traces with value shapes and ownership per step |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | 10 bad-vs-better pairs exposing novice instincts (all fake, all labeled) |
| [04-review-katas.md](04-review-katas.md) | 9 fake PRs to review with blocking/important/optional findings |

Rules: write your answers before reading answer keys; grade honestly against the rubrics; when a drill says "verify in the repo," actually open the file. Timed variants of the best drills live in [08-interview-prep/05-debugging-and-code-review-rounds.md](../08-interview-prep/05-debugging-and-code-review-rounds.md).
