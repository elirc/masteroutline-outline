# 07 — Career and Collaboration

Code gets you to mid-level; communication gets you past it. This module trains the written artifacts and habits that determine how your work lands: reviews, PRs, RFCs, and maintainer interactions. All three pages use this repo's real conventions as the practice field.

| [02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md) | PR descriptions, commit messages, when and how to RFC |
| [03-maintainer-communication.md](03-maintainer-communication.md) | Asking well, reporting bugs, disagreeing productively — with templates |

Interview relevance: behavioral rounds ("tell me about a disagreement", "how do you handle review feedback") are graded on exactly these skills; the [STAR worksheets](../08-interview-prep/06-behavioral-star-stories.md) draw on the habits here.
